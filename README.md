# ChatGPT RTL Local 0.2.1

הרחבה מקומית ל־Brave, ל־Chrome ול־Edge במחשב. היא מתאימה את כיוון הטקסט בשיחות באתר ChatGPT ובשדה ההקלדה.

## התקנה בכל מחשב

1. חלצו את ה־ZIP במחשב לתיקייה שתישאר אצלכם.
2. פתחו `brave://extensions` ב־Brave,‏ `chrome://extensions` בכרום או `edge://extensions` ב־Edge.
3. אם הגרסה הקודמת פעילה, כבו אותה. הפעילו **Developer mode**.
4. לחצו **Load unpacked** ובחרו בתיקייה `chatgpt-rtl-local` שמכילה את `manifest.json`.
5. ודאו שמופיעה גרסה `0.2.1`. רעננו את `chatgpt.com`.

כדי להשוות, כבו את ההרחבה ורעננו את האתר. כדי לעדכן, טענו את התיקייה של הגרסה החדשה בכל מחשב בנפרד.

## בדיקה קצרה

הקלידו `API Gateway מחזיר שגיאה רק אחרי שהחיבור נפתח (HTTP 502).` בשדה ההקלדה. הכיוון אמור לעבור לימין. אחרי השליחה, תחילת המשפט `API Gateway` אמורה להופיע בצד ימין של שורת ההודעה, ו־`HTTP 502` בצד שמאל שלה. אם כבר שלחתם את המשפט בעבר, אפשר לבדוק אותו באותה שיחה אחרי רענון. כשתקלידו טיוטה באנגלית, הכיוון אמור לעבור לשמאל.

בצ׳אט חדש בקשו תשובה עם פסקה עברית שמתחילה ב־`API Gateway`, פסקה באנגלית, רשימה, טבלה, נוסחה ובלוק קוד. בדקו את הכיוון תוך כדי הופעת התשובה ואחריה. הקוד והנוסחה אמורים להישאר משמאל לימין. הטבלה שומרת על סדר העמודות. אם יש ספק, כבו את ההרחבה, רעננו את אותה שיחה והשוו.

## פרטיות ותאימות

הקוד מופעל רק ב־`https://chatgpt.com/`. הדפדפן נותן לו גישה לתוכן העמוד כדי לזהות את כיוון הטקסט. בקוד שבחבילה אין קריאות רשת, אחסון, ספריות צד שלישי או הרשאות API נוספות. ההתקנה מקומית בכל פרופיל דפדפן.

זיהוי הכיוון מבוסס על האותיות בטקסט. בפסקה כמעט מאוזנת או בטיוטה שיש בה כמה שפות הוא יכול לבחור כיוון שונה מהכוונה שלך. שדה ההקלדה מקבל כיוון אחד לכל הטיוטה. שינוי במבנה של אתר ChatGPT יכול להצריך עדכון. ההרחבה מיועדת לדפדפן במחשב. באפליקציה לנייד אפשר להגדיר הוראות מותאמות אישית שמשפיעות על ניסוח התשובות.
